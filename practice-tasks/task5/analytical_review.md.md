# Аналитический обзор (задача №1)

## Функциональность
Корректно находит сумму отрицательных элементов между максимальным и минимальным. Обработаны краевые случаи.

## Производительность
Сложность O(n). Для 10⁶ элементов работает <0.1 сек в Python.

## Удобство использования
Простой вызов функции, понятные аргументы.

## Безопасность
Нет уязвимостей, т.к. нет ввода-вывода.

## Масштабируемость
Легко модифицировать (сумма положительных, вещественные числа и т.д.)

## Сопровождаемость
Код читаемый, с комментариями.

## Переносимость
Python 3, работает на всех ОС.

## Качество кода
Соответствует PEP8, модульное тестирование.

## Тестирование
Проведены тесты на основных сценариях.

## Выявленные проблемы и решения
- Проблема: при нескольких одинаковых максимумах берётся первый индекс. Решение: уточнение ТЗ.
- Проблема: пустой массив. Решение: добавить проверку.
