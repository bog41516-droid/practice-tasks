# Практика: Технологическая (проектно-технологическая) практика

## Кейс-задачи

- **Задача №1** – сумма отрицательных элементов между максимумом и минимумом (Python).
- **Задача №2** – демонстрация методов базового и производного классов (Python).
- **Задача №3** – проектирование БД «Туризм» (SQL).
- **Задача №4** – WEB-приложение на Delphi + IIS + MS SQL (аналитика и каркас).
- **Задача №5** – аналитический обзор выбранной задачи.

## Как использовать

Каждая задача находится в отдельной папке с соответствующим именем.
